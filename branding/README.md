# Branding

This directory holds the **GridPilot MCP** visual source of truth for repository-facing presentation.

## Visual system

- **Primary palette**
  - deep navy: `#08131E`
  - charcoal: `#1F2933`
  - grid green: `#0F6A4A`
  - bright green: `#14B88A`
  - teal accent: `#22D3EE`
  - soft light text/backgrounds: `#E5E7EB`, `#F4F7F9`, `#FFFFFF`
- **Type direction**
  - sans-serif for narrative and product framing
  - monospace only for commands, tool names, and technical flow labels
- **Tone**
  - precise
  - calm
  - premium
  - technical, not playful

## Asset usage

- Use `assets/logo.svg` on light backgrounds.
- Use `assets/logo-dark.svg` on dark backgrounds.
- Use `assets/icon.svg` and `assets/icon-dark.svg` the same way for compact marks.
- Prefer SVG for README and docs visuals so GitHub renders them crisply.

## Repo presentation kit

The GitHub-facing presentation layer should standardize on these reusable visuals:

- `assets/github-hero.svg`
- `assets/architecture-overview.svg`
- `assets/workflow-overview.svg`
- `assets/surface-map.svg`

Keep future repo-facing visuals here rather than scattering them through `docs/`.
