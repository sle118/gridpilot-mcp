# Branding

This directory contains the current GridPilot MCP brand assets folded into the repository structure.

## Files

- `assets/logo.svg`
- `assets/logo-dark.svg`
- `assets/icon.svg`
- `assets/icon-dark.svg`
- reference branding boards in PNG format

## Usage guidance

Use the SVG assets for repository-facing material, documentation, and later package/application surfaces.

The current overlay only adds repository branding. It does not rename the starter C# solution or namespaces.
