# Worklog directory

Create one dated file per work session or meaningful task slice.

Suggested filename format:
- `YYYY-MM-DD-short-title.md`

Suggested template:

```md
# Worklog: YYYY-MM-DD - short title

## Goal
What this session intended to achieve.

## Changes made
Concrete code, docs, or test changes.

## Findings
Important discoveries or constraints.

## Decisions taken
Local decisions taken during the session.

## Tests
What was run and what happened.

## Next
Immediate next steps.
```
